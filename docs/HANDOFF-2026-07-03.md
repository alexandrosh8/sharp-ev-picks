## What this project is

A **picks-only** betting decision-support platform (never places bets — hard
architectural rule, CI-enforced by `scripts/safety_audit.sh`). It scrapes odds
(OddsPortal), anchors fair value against sharp sources (Pinnacle ARCADIA
close, Betfair Exchange), strips vig, gates +EV edges, sizes fractional-Kelly
stakes as information only, alerts, settles, and tracks ROI/CLV. The user
reviews every pick and bets manually outside the system. Full architecture:
`docs/architecture.md` (rewritten 2026-07-02, accurate as of today).

Repo: `https://github.com/alexandrosh8/sharp-ev-picks` — `main` branch only,
direct-to-main workflow (operator preference, no PRs). Deploys from
`/workspace` via `docker compose --profile prod` (NOT `/opt/betting-ai-new`,
which is a stale clone — see project memory).

## Tooling notes for whoever picks this up

- **Playwright on this host**: the standard `chromium` distribution needs a
  root-owned Chrome binary the sandbox doesn't have. What DOES work: `uv run
  --with playwright playwright install chromium` (downloads a headless-shell
  build to `~/.cache/ms-playwright`), then `apt-get download` (no root
  needed, just fetches .deb files) + `dpkg -x` to extract the needed shared
  libs user-space into a scratch dir, then run with
  `LD_LIBRARY_PATH=<scratch>/extracted/usr/lib/x86_64-linux-gnu`. The
  missing-lib list discovered this session: `libnspr4`, `libnss3`,
  `libatk1.0-0`, `libatk-bridge2.0-0`, `libatspi2.0-0`, `libcups2`,
  `libxkbcommon0`, `libxcomposite1`, `libxdamage1`, `libxfixes3`,
  `libxrandr2`, `libgbm1`, `libpango-1.0-0`, `libcairo2`, `libasound2`,
  `libdrm2`, `libdbus-1-3`, `libexpat1`, `libxcb1`, `libx11-6`, `libxext6`,
  `libwayland-server0`, `libxi6`. Screenshots from this session live under
  `/tmp/.../scratchpad/redesign/` (ephemeral — regenerate if needed).
- **CI**: no `gh` CLI on this host. Use the GitHub REST API with the token
  from `git credential fill <<< $'protocol=https\nhost=github.com\n'`. The
  `/logs` endpoint 302-redirects to blob storage — don't forward the
  Authorization header on the redirect (401s). **Always poll CI to green
  after every push** — this project's DB-backed tests (~180 of them) skip
  silently in this sandbox (no route to `127.0.0.1:5433`) but run for real
  in CI, so local green does NOT prove CI will pass. This bit us once
  already (CI #422-424 failed on a test-isolation bug local runs couldn't
  see).
- **Deploy**: `docker compose --profile prod build app` then
  `up -d --force-recreate app` from `/workspace`. Entrypoint auto-runs
  `alembic upgrade head`. Verify with `docker compose --profile prod exec
  app uv run alembic current` and a `/health` check.
- **Reading prod logs / DB**: `docker compose --profile prod logs --since
  Nm app`; `docker exec betting-ai-postgres-1 psql -U betting_ai -d
  betting_ai -c "SELECT ..."` (read-only queries only, never DDL/DML against
  the live DB from an agent session).
- **Karpathy guidelines**: operator wants
  `~/.claude/skills/karpathy-guidelines` (think-before-coding,
  simplicity-first, surgical changes, goal-driven execution) applied on
  every coding task — it's saved as a standing memory rule
  (`always-karpathy-guidelines.md`).
