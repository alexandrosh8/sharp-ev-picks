LIVE — fresh re-price, pre-kickoff, value still present; provisional until kickoff. Confirm the current price at your book yourself.
UNVERIFIED — pre-kickoff but the last re-price is stale (or value gone); returns to LIVE next cycle.
CLOSED — kicked off: the line closed, CLV is final, awaiting the settled result.
RESULTS — every kicked-off pick merged: won/lost/awaiting plus recorded settlements + P&L.
